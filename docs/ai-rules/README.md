# AI Rules

Regras e diretrizes para desenvolvimento assistido por IA neste projeto.

Descreva aqui:

- Convenções de código a seguir (padrões de nomenclatura, estilo, estrutura de pastas)
- O que a IA pode e não pode fazer sem confirmação (ex: alterar banco, criar dependências)
- Como a IA deve se referenciar às especificações em `overview/` e `data/` antes de implementar
- Ferramentas/stack permitidas
